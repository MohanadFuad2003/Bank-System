# C++ Console Application Project  

## 🎯 Project Goal  
The main objective of this project is to write **clean code** using:  
- **Divide and Conquer** technique (breaking down problems into smaller parts and solving them step by step).  
- Applying one of the **SOLID Principles**:  
  - **Single Responsibility Principle (SRP)** – ensuring each module/class has one clear responsibility.  

---

## 🗄️ Database  
- A simple **DBMS** without relations between tables.  
- The database is implemented using **text files (.txt)**, similar to **XML/JSON** structures.  

---

## 🔑 Login System  
- Users can log in with their credentials.  
- **Admin** has full access.  
- Other users have limited permissions.  

---

## 🔒 Access Permissions  
- Permissions are managed using **bitwise operations**.  
- Each user has a permissions number that defines which pages and operations they can access.  

---

## ⚙️ Supported Operations (CRUD & More)  
- Full support for **CRUD operations** (Create, Read, Update, Delete).  
- Additional operations as required by the project.  

---

## 💱 Currency Conversion  
- The system supports **currency conversion** functionality.  

---

## 📜 Log File  
- All login attempts are recorded in a log file.  
- The log file contains **time, date, and user login information**.  

---

## 💸 Money Transfer  
- Users can **transfer money** to other users within the system.  

---

## 📂 Additional Requirements  
- Other requirements are included in the project and can be explored after downloading and running it.  

---

## ▶️ How to Run  
1. Download the project.  
2. Open it in **Visual Studio**.  
3. Press **F5** to run the project.
