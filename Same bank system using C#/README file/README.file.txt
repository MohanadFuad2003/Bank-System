# BankSystemAPILayer

A simple banking system built with a **3-Tier Architecture :  

- Data Access Layer (ADO.NET with SQL Server)**
- Business Access Layer (Business Logic using C# language)
- API Layer (RESTful-API using asp.net core controller ,  endpoints, Swagger UI)


- The goal of this project is to migrate an existing banking system originally built as a C++ console application to a modern C# solution using .NET Core. This includes building a RESTful API and leveraging ADO.NET for database operations.
